# Instruções do Agente

- Este projeto utiliza a memória persistente do `ai-memory` via MCP.
- Antes de iniciar uma tarefa grande ou alterar arquiteturas existentes, consulte o `ai-memory` para verificar decisões passadas.
- Sempre que concluir um ciclo de trabalho ou encontrar uma solução complexa de bug, salve uma observação no `ai-memory`.
